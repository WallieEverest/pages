GitHub

To upload changes straight from this device, connect a GitHub token (once per device). Create a token: under Repository access choose Only select repositories → pages; under Permissions set Contents to Read and write. GitHub then adds Metadata: Read-only by itself; that's required, so leave it. Then paste it here.
